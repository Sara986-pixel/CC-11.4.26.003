Create a beautiful, interactive personality quiz website titled "What Type of Lover Are You?"
The website should determine a person's romantic personality through 10 engaging, relatable questions about love, relationships, attachment, emotions and romance.
Design aesthetic:

* Romantic, vintage, Pinterest-inspired design.
* Dusty pink, burgundy, cream and muted brown colour palette.
* Elegant serif typography combined with handwritten fonts.
* Subtle animations, floating hearts and paper textures.
* Beautiful transitions between questions.

Quiz functionality:

* 10 multiple-choice questions.
* Interactive answer selection.
* Animated progress bar.
* Personality-based scoring algorithm.
* Unique results based on the user's answers.

Personality results:
Include different romantic archetypes such as:

* The Hopeless Romantic
* The Lover Girl
* The Yearner
* The Secret Admirer
* The Nostalgic Lover
* The Old-School Romantic
* The Overthinker
* The Heartbreaker

Music integration:
Each personality result should feature a matching song, artist, short description and a brief lyric excerpt.
Include artists such as:

* The Neighbourhood (particularly Reflections)
* Lana Del Rey
* Arctic Monkeys
* Taylor Swift
* Coldplay
* Lord Huron
* The Walters

Use short, legally permissible lyric excerpts rather than reproducing full copyrighted lyrics.
Result cards:
Each result should display:

* Romantic personality title.
* Personality description.
* Matching song and artist.
* Short lyric excerpt.
* Biggest strength in love.
* Biggest weakness in love.
* Ideal romantic partner.

Include a restart button and an option to share the result.
Technology:
Build using HTML, CSS and vanilla JavaScript. Keep the code organised into three separate files: index.html, style.css and script.js.
Make the website responsive, functional and visually polished on both desktop and mobile.
